## 统一加工参数（六条视频共用，务必保持一致）

```
--size=580x720 --crop=345,0,580,720 --bg=auto --threshold=70 --soft=26 --extract-fps=24 --fps=12 --no-loop
```

- **`--bg=auto` 是必须的**：这些视频的背景不是 `#00FF00`，而是 `rgb(73,166,66)` 一类的哑光绿，
  且逐帧漂移（10 秒内漂到 `rgb(73,158,71)`）。用 skill 默认的纯绿阈值 110 → 抠图整个失效。
- **`--crop` 固定窗是必须的**：角色带法阵/法杖光效，逐帧 bbox 被撑到画面边缘且剧烈变化
  （宽度幅度 149px / 40%），而角色质心只漂 25px（2%）→ 任何 bbox 对齐都会跟着光效抖。
- **裁剪窗的来源**：A/B 两条片子角色本体 x 范围合并后是 `[372, 899]`，两侧各留 ~26px 余量 →
  `x∈[345,925)`，取宽 580、整高 720。C（`[386,853]`）和 D（非喷射段 `[363,890]`）都落在窗内，
  所以四条共用同一窗、无需重跑。**新素材必须复用同一窗**，否则角色在段间会变大小/跳位置。

## 腿的问题（已拍板：保持 7 区分开）

你给的**五段腿部反应里，四段都是同一条腿**（你说的"右腿"＝角色右腿＝**画面左腿** `legL`），
已逐帧放大确认抬起/踢出的都是画面左侧那条。

唯一的例外是 F 段 `feet_tap`（左右交替踏脚）—— 逐帧量过左右脚底高度，
两只脚确实都动（画面右脚在 `4.08–4.25s` 和 `5.33–5.58s` 各抬一次）。但**抬起幅度只有 15–19px**，
是"踏"不是"踢"，拆成两条单腿动画各自都读不出来，所以整段当成**双腿共用**。

**决定：保持 7 区分开**（标定时两条腿分别画了框）。
于是 `legR` 目前只能吃 `feet_tap` 这一个共用变体 —— 连戳右腿会重复。
要补的话，需要一段**幅度明显的角色左腿单腿动作**（`feet_tap` 那种 15px 的踏脚不够）。

标定时你把 `legL`/`legR` 两个框怎么画，其实就已经回答了这题 —— 画成一个覆盖双腿的大框
即为方案 1，我按你的框走。

## 背景素材（`assets/bg/`）

魔女工房·塔内，三层。**由 `agy`（Nano Banana）生成，不是视频抽帧**，所以和角色素材
不共用任何加工参数。源图 `assets/bg/raw/*.png`（gitignore），产物 webp 入库
（Cloudflare CI 部署要读，见 CLAUDE.md）。

| 层 | 产物 | 大小 | 绿幕 | 内容 |
|----|------|------|------|------|
| `far` | `far.webp` | 67KB | ❌ 不透明整图 | 塔内穹顶、玫瑰窗光柱、星图天花 |
| `mid` | `mid.webp` | 120KB | ✅ 抠成透明 | 左书架药瓶 / 右壁炉坩埚石阶 / 底部石板地带 |
| `fore` | `fore.webp` | 62KB | ✅ 抠成透明 | 左干草药书堆 / 右帷幔烛台 / 底部石板条 |

> **远景不走绿幕**：它没有主体要抠，走绿幕只会得到一圈绿边 —— 背景要整张不透明图。
> **中景「中央留空」不是硬要求**：它在角色之后，内容越界到中央不构成遮挡。
> 只有前景是硬要求（生成时中央 60% 必须是纯绿）。

### 加工与定标（两步，顺序不能反）

```
node tools/process-bg.mjs      # 抠图 + despill + 归一到 1440×1152 + 前景中央占用率体检
node tools/measure-bg.mjs      # 量三层地面线 → 回填 game/config.js 的 PM.Config.BG
```

- `process-bg.mjs` 带两道体检：**纯绿空图判定**（agy 有静默产出全绿图的前科）和
  **前景中央占用率**（>12% 就会挡住角色）。本批 fore 报 14.5%，超的那部分是底部石板条，
  已由 `scale`/`scaleX` 在装配侧推出角色范围，不必重生图。
- `measure-bg.mjs` 给的是**候选不是答案**：far 的「最强水平边」量到的是平台后沿（y=653），
  照它定标角色会站到半空；真正的地板交界在第二候选 y≈989。哪条线是"角色该站的那条"要人眼定。
- 重新生图后**必须重跑这两步并回填**，不要沿用旧 scale。

### 生成提示词的三条硬要求

1. 中景/前景的空处必须写明 **pure flat chroma green rgb(0,255,0)，no gradient no shading**，
   并说明「这块会被抠成透明」—— 不说清楚模型会给带阴影的绿，抠出来一圈脏边。
2. 前景要**逐块指定**：左列画什么、右列画什么、底部条多高，中央必须空。
   笼统写「前景框架」会得到糊满整幅的图。
3. 尺寸写 **1440×1152（5:4）**。画布是近竖幅，16:9 的源图铺满高度会把左右各裁掉三分之一。
