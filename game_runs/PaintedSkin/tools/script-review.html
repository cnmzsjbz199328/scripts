怎么用
  • 每条台词、旁白、选项都有一个改写框，原文已填好，直接改字就是定稿替换；下方会显示与原文的对照。
  • 拿不准怎么改，就点 ＋ 意见 写方向（语气、删改理由、想要的效果），由 Claude 改写。改写框和意见可以同时用。
  • 清空改写框 = 删除此条；在改写框里换行 = 拆成多段（新的一段要换人说，就写成「陈氏：……」）。
  • 左侧色条和下拉框是说话人；把下拉框改成「旁白」或某个角色，就能把台词和旁白互换。
  • 字数：台词和旁白建议 ≤ 60、硬上限 80；选项上限 18。超出会标黄或标红。
  • 草稿自动存在这个浏览器里。改完点右上角 导出给 Claude，复制后贴回对话。等 Claude 改完、重新构建，刷新这一页就能看到新文本，然后清空草稿开始下一轮。
